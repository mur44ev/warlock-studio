# Warlock Studio v2.1.0 + AW60 rev9

Первый публичный релиз программы Windows x64 и прошивки для проверенной
Warlock / GP75 model919 v1.04 (YC3121-L).

- Metro UI,19 автономных эффектов,5 реактивных,80 per-key цветов.
- USB и2.4GHz, локальная анимация около60FPS без потока кадров от компьютера.
-50 persistent preset slots, Base/Fn remaps, профили и диагностика.
- **Rev9 исправляет порчу раскладки/Enter из-за пересечения RGB SRAM со штатным
  буфером записи keymap.** Предыдущие ревизии не публикуются.
- После исправления владелец подтвердил набор/Enter/Fn по USB и свистку;
  автоматическая радио-проверка20/20, слои целы после анимации и stock-запросов.

Скачайте архив программы и распакуйте целиком. Архив прошивки предназначен только
для совместимого model919/1.04; запись явно включается `--flash`, по кабелю.
Инструкция/ограничения: README и docs/firmware.md. Принудительный аппаратный
unbrick не проверен. Макросы в текущем Studio заменены слотами RGB-пресетов.
